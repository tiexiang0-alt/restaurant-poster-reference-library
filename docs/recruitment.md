# 招聘海报分类

## 分类目标

招聘海报不是品牌形象海报的缩小版。国内餐饮招聘的核心阅读顺序通常是：

1. 是否正在招聘；
2. 招什么岗位；
3. 工资与待遇；
4. 任职要求；
5. 如何联系。

创意必须帮助以上信息更快被看见。只提供“高级、日系、上海感”等风格词，却没有真实案例结构，不属于本数据库的合格输入。

## 六个实战案例家族

### R001｜商场 A 型水牌

适合岗位少、观看距离较远的门店。超大单字先完成“招聘”识别，岗位薪资列表随后承接。若用于铁毅祥，建议保留“巨字＋短列表”，换成品牌红、米白与深森林绿。

### R002｜牛皮纸编辑式

适合需要说明职责、工时和福利的招聘。信息框、序号和粗黑标题构成完整编辑系统。注意正文不能缩得过小。

### R003｜红色传统餐饮型

适合传统中餐门店。红底和书写巨字具有强烈招聘语义，岗位薪资与福利资格分区直白有效。书写字只能做主视觉，不能取代岗位信息。

### R004｜场景摄影型

适合岗位较多、希望展示工作氛围的品牌。真实餐饮场景是证据，文字则需通过遮罩、渐变或稳定区域保证可读。

### R005｜红金连锁信息表型

适合一次招聘多个岗位。岗位、人数和工资以表格方式对齐，信息密度高但扫描效率也高。模板水印、示例二维码和虚构福利不得继承。

### R006｜系列模板型

适合长期招聘。保持背景、字体、信息卡和色彩一致，只改变标题方向、信息卡方向和岗位组合。它的价值在于“系统”，不是森林背景本身。

## 禁止事项

- 不得虚构工资、奖金、月休、食宿、晋升、地址或二维码。
- 不得把示例案例的电话号码、品牌名或水印带入铁毅祥海报。
- 品牌名必须逐字等于“铁毅祥河洛面”，不接受任何替代写法。
- 不得为了“高级感”缩小岗位和电话。
- 不得把六个案例的装饰元素全部堆进一张海报。
