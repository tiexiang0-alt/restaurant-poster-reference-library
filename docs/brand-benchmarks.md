# 品牌招聘基准案例

本页收录 20 张用户提供的品牌招聘截图。它们是“设计机制研究样本”，不是品牌官方素材包，也不是可直接调用的商业素材库。

## 证据与权利边界

- `brandShown` 只转录画面可见品牌文字；无法可靠辨认时写“未识别”。
- 所有案例的 `officialStatus` 均为 `unverified`。出现知名商标，不等于已证明由品牌官方发布。
- 所有图片均为 `reference-only`，不可从仓库推定公开再分发或商业复用权。
- 可迁移：构图骨架、信息层级、系列化方法、阅读顺序、模块关系。
- 不可迁移：Logo、商标、品牌专属色组、吉祥物、产品杯、建筑插画、人物摄影、二维码、原文案和联系方式。

## 四类成熟方法

### 1. 品牌资产不是装饰，而是版式骨架

R007、R012、R016、R023 把品牌色、门店、产品或文化图像放在固定区域，招聘信息则进入独立安静区。迁移到铁毅祥时，应改用品牌红、河南郏县河洛面的自有食品/门店资产，不能复制他牌 Logo 或产品图。

### 2. 系列化靠固定组件，不靠每张重做

R007–R008 与 R016–R018 证明：固定标题位置、信息模块和视觉锚点后，只更换岗位深度、城市或季节主题，就能形成稳定 Campaign。

### 3. 门店物料优先解决视距

R015、R022、R026 的共同点是标题大、信息块少、联系方式落底。A4 竖版或水牌必须先确保三米外知道“在招聘”，一米内读清岗位与电话。

### 4. 不同招聘层级需要不同信息密度

- 门店基础岗位：岗位、待遇、电话优先。
- 多岗位集中招聘：按前厅/后厨或管理/基础分组。
- 总部/校园招聘：面向人群、岗位范围、福利与投递方式模块化。
- 配送或特殊岗位：规则与工作内容必须完整说明，适合文本公告型。
