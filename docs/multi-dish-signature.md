# 多菜品与招牌菜海报

第二大类收录 20 张用户提供案例，编号 **D001–D020**。本类研究的不是单张菜品摄影，而是“如何在一张海报里同时卖多道菜”。

## 核心结论

多菜品海报的第一决策不是颜色，而是菜品层级：

| 业务问题 | 推荐结构 | 代表案例 |
|---|---|---|
| 一款招牌菜带两三款辅助菜 | 主菜＋辅菜 | D001、D007、D009、D012、D013、D015 |
| 三至四款菜同级推荐 | 等权矩阵 / 季节宴席 | D003、D011、D016 |
| 菜名与价格必须快速点单 | 价格菜单 | D010、D014 |
| 窄幅门店灯箱 | 纵向堆叠 | D018、D019 |
| 套餐要显得丰盛且划算 | 密集套餐堆叠 | D006 |
| 地域小吃或市井感传播 | 抠图拼贴 | D008、D017、D020 |
| 强调食材与高级质感 | 场景化静物 | D002 |
| 比较一套系列的多种版式 | 作品集索引 | D004、D005 |

## 八种版式家族

### 1. 主菜＋辅菜 `hero-support`

主菜面积通常为辅菜的 1.25–1.8 倍。优先用尺寸、位置和动作道具建立主次，不要仅靠给主菜加更多文案。

### 2. 等权菜品矩阵 `equal-weight-grid`

适合三至四款同级新品。统一器皿、光向、盘径或背景，是避免“菜单截图感”的关键。

### 3. 纵向阶梯 `vertical-stack`

适用于商场灯箱与窄墙面。每款菜必须在同一高度同时出现“菜图＋菜名＋价格/卖点”，不能把名称集中放到底部。

### 4. 抠图拼贴 `cutout-collage`

适合地域小吃、夜宵和年轻化传播。所有抠图应统一描边、阴影、透视和光向；地标、人物、手部与街景均需另行核验授权。

### 5. 场景化静物 `scene-still-life`

以材质、器皿、原料和景深串联菜品。信息量宜少，卖点应贴近实物标注，不适合远距大段小字。

### 6. 价格菜单 `price-menu`

菜名、价格、产品图构成不可拆分的商品单元。更新价格时必须作为一组维护，避免跨行错配。

### 7. 季节宴席 `seasonal-feast`

用背景色、植物、器皿和主题标题建立季节氛围，但“夏日”“秋冬”等文案必须与真实售卖周期一致。

### 8. 系列作品集 `series-contact-sheet`

D004、D005 是研究索引，不是可直接生成的成品模板。使用时必须从拼图中选择一种机制，不能把多个缩略图的风格混合进一张海报。

## 食物图像规范

1. 同一张海报中的盘子应尽量共享光向、白平衡和视角。
2. 主菜依靠尺寸与位置建立层级；菜品数量越多，背景越应简化。
3. 菜名必须靠近对应菜图，价格与商品不可跨栏。
4. 原料只在真实配方中出现；不得用辣椒、番茄、山林等素材制造虚假配方或产地暗示。
5. 截图黑边、平台 UI、作者水印、二维码、作品集标识不是设计元素，生成或重制时必须排除。
